# Single Photon Lithography 3D Printing on the Nanoscale

## Introduction
- You should allocate one machine to use to send code to the printer because the application needs a different setup depending on the device it
is being run on. While it is not arduous, this setup does take up a large amount of time. 

## Installation
- You will need to install Visual Studio Community edition in order to run this code. When installing, include the .NET desktop development workload.
- Install Visual Studio here: https://visualstudio.microsoft.com 
- You also need to install Kinesis.
- Install Kinesis here: https://www.thorlabs.com/Software/Motion%20Control/KINESIS/Application/Web_Download_Readme/Web_Download_Readme.htm
- Connect Visual Studio to GitHub and clone this repository.

## Usage
- If your system does not match the system states in the variables to edit section then you will have to delete and re-add the resource and debug files.
- Follow instructions from page 12 onwards to setup the console application for your device.
- Thorlabs C# Instructions here: https://www.thorlabs.com/Software/Motion%20Control/KINESIS/Kinesis%20with%20C%20Quick%20Start%20Guide.pdf
- If you do this, please update the system info section in the program.cs file.
- Please make edits in seperate branches and then apply them to the master branch when they have been tested.
- Do not delete the sub branches as they allow us to check different functionalities if errors start occuring later down the line.

- Refer to the printing guide for instructions on how to use the 3D Printer.
